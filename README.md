# 🏠 House Price Prediction

A machine learning project that predicts house prices using Linear Regression and provides an interactive Streamlit dashboard for house price analysis.

## 📌 Project Overview

This project uses a house price dataset to:

- Analyze housing data
- Visualize house price trends
- Compare regression models
- Predict house prices
- Display model performance
- Provide an interactive dashboard

## 🤖 Machine Learning

The following regression models were compared:

- Linear Regression
- Ridge Regression
- Lasso Regression
- Decision Tree
- Random Forest
- Gradient Boosting

### Final Model

**Linear Regression**

- **R² Score:** 0.6967
- **MAE:** $121,974.94
- **RMSE:** $212,420.98

## 📊 Streamlit Dashboard

The dashboard contains:

- Housing market overview
- Price distribution
- Price by bedrooms
- Living area vs price
- City-wise price analysis
- House age analysis
- House price prediction
- Model comparison
- Actual vs predicted analysis
- Residual analysis
- Dataset explorer
